DATA AND INTERPRETATION

Temperature: 35 common complete curves at each temperature. Strict monotonicity
is 28/35, 26/35, 19/35 and 15/35 at temperatures 0, 0.3, 0.7 and 1 respectively.
There were 20,159 parsed responses out of 20,160 planned requests. One failed
request leaves one curve incomplete; that curve is excluded at every temperature.
The 12 ladders and three shared comparison statements are a descriptive pilot.

Direct ranking: 23 primary API configurations, 100 canonical ladders each.
Scores use 2,241 valid rankings out of 2,300 logical requests under the original
parser. Per-model valid denominators are printed in the figure. The source CSV
also reports a separate sensitivity check recovering 33 formatting-only cases;
those cases are not silently added to the plotted primary results.
This is agreement with the intended ordering, not an independent transitivity test.
GLM Base (log-probability scoring) is not part of this text-ranking task.

REPRODUCE THE FIGURES (repository checkout with dependencies installed)

PYTHONPATH=src python -m llm_coherence.reporting.followup_figures
PYTHONPATH=src python -m unittest discover -s tests -v

The generator verifies the curated CSV hashes, response denominators, model slate,
and common complete-curve mask before exporting. data/provenance.json identifies
the local source files and canonical ladder hash. data/ranking_audit.json and
data/temperature_audit.json record the source response hashes. Raw model outputs
and credentials are not included in this report. Reproducing the upstream raw
response audits also requires the original local outputs and audit code; this
PR reproduces the figures from the curated aggregate exports.

CSV line endings are normalized to LF for version control. Both the original
source hashes and the normalized-file hashes are recorded in provenance.json.
